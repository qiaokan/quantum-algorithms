An observable is represented by a Hermitian matrix $O=O^\dagger$. Its eigenvalues are the possible numerical outcomes in its eigenbasis measurement. The expected value is $\langle\psi|O|\psi\rangle$, or $\operatorname{Tr}(\rho O)$ for a mixture.

For $Z=\operatorname{diag}(1,-1)$, measuring bit 0 is assigned value +1 and bit 1 value −1. In $(\sqrt3|0\rangle+|1\rangle)/2$, the expectation is $(3/4)(+1)+(1/4)(-1)=1/2$. No single shot returns 1/2; that is the long-run mean.

$X=\left(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\right)$ and $Y=\left(\begin{smallmatrix}0&-i\\i&0\end{smallmatrix}\right)$ are other Pauli observables. Measuring $X$ can be done by $H$ then computational measurement. Several noncommuting observables usually need separate prepared copies.
